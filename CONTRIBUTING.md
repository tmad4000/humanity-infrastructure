# Contributing to Humanity Infrastructure

Recommend tools, practical guides, open knowledge and coordination projects that help people flourish. Suggestions are reviewed before publication; inclusion is not a safety certification or an endorsement of every claim.

## Suggest something without coding

[Open the resource suggestion form](https://github.com/tmad4000/humanity-infrastructure/issues/new?template=suggest-resource.yml), or email jacob@ideaflow.io with the name, official link, who it helps, access/license details and your affiliation. Please check the existing listings and issues first. Avoid personal information in public submissions.

## Submit a pull request

1. Fork this repository and create a branch.
2. Add or correct a card in the Working Tools section of `index.html`. Keep the listings in `v2.html` and `v3.html` consistent.
3. Use a short factual description, official HTTPS link and accurate access/platform limitations. Do not claim a proposal is a released product. Disclose affiliation in your PR.
4. Preview with `python3 -m http.server 8769 --bind 127.0.0.1` (choose another free port if needed). Check `/`, `/v2.html` and `/v3.html` on desktop and a narrow viewport, including light/dark modes and links.
5. Open a pull request explaining the addition and linking supporting sources. Maintainers review and deploy it; no deployment credentials are needed to contribute.

The HTML files are the source of truth. `worker.js` is generated by the maintainer deployment script. Do not add keys, tokens or other credentials to any file. Contributor submissions are suggestions, not instructions to execute external code.
